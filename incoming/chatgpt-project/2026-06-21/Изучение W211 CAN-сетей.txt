TARS: изучил. Это учебный материал Mercedes-Benz USA по CAN-сетям, не полноценный WIS-мануал. Он сам предупреждает: использовать как справочник, но по конкретной машине сверяться с актуальным WIS/схемами.

Главное для **W211**:

**1. В W211 есть несколько сетей**
- **CAN B** — interior/body bus: двери, SAM, климат, сиденья, OCP/UCP, Parktronic, TPMS, AGW и т.д.
- **CAN C** — engine/chassis bus: ME-SFI, ESP, EGS/ETC, selector, suspension, Distronic и т.д.
- **CAN D** — диагностическая шина между **N93 Central Gateway**, **N112 TeleAid/communication platform** и SDS/DAS.
- **MOST** — аудиосеть.

**2. Для W211 важен уже не только EIS, а N93 Central Gateway**
В ранних примерах PDF EIS описан как gateway между CAN B и CAN C, но в разделе W211 центральным узлом уже выступает **N93 Central Gateway Module**. Для нашего проекта это важно: не надо думать, что всё “живет” только через замок зажигания.

**3. Физические точки подключения по PDF**
- **CAN C X30/5** — водительский порог / wiring trough.
- **CAN B X30/4** — правая сторона пассажирского footwell.
- **CAN B X30/6** — пассажирская сторона, корпус HVAC.
- **CAN B X30/7** — водительский порог / wiring trough.
- **Rear SAM N10/2** — слева в багажнике; через него подключены несколько модулей CAN B.

**4. OBD — это не “просто весь CAN автомобиля”**
Для W211 PDF прямо показывает **CAN D через X11/4 / OBD**:

- pin **6** — CAN High, зелёно-белый;
- pin **14** — CAN Low, зелёный;
- покой: оба около **2.5 V**;
- активность: High примерно до **3.5 V**, Low примерно до **1.5 V**.

То есть через OBD мы видим диагностический путь через gateway, а не обязательно сырой CAN B с кнопками, дверями и внутренними событиями.

**Вывод для KITT/W211:**

Для безопасного старта:

1. **OBD/CAN D** — диагностика, чтение через gateway, самый удобный вход.
2. **CAN B** — нужен для дверей, кнопок, света, салонных событий, “машина говорит, что происходит”.
3. **CAN C** — двигатель/шасси; трогать осторожнее, сначала только read-only.
4. **CAN B нельзя слепо считать обычным high-speed CAN.** В PDF для Mercedes CAN B указаны нестандартные напряжения и 83 kbps. Значит, обычный USB-CAN адаптер может быть нормален для CAN C/CAN D, но для CAN B надо проверять совместимость трансивера и схемы по конкретному W211.

Диагностическая логика из PDF тоже полезная: при проблемах CAN Mercedes предлагает смотреть напряжения, осциллограмму, статус через DAS/SDS и изолировать ветки через X30-коннекторы, отключая и подключая линии, пока сеть снова не станет unstable/stable.

Зафиксировал для проекта. Следующий логичный шаг — сделать карту подключения Raspberry Pi/PCAN к W211 отдельно для **CAN D / CAN B / CAN C** с рисками и точками доступа.
